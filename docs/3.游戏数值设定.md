## 0. 使用说明

- 实现方式：本文件每张表对应改版工程 `src/data/` 目录下的一个 JSON 数据文件（设计文档 §12 代码落位映射），改数值不改代码：
  - 角色 → `characters.json`；职业 → `classes.json`；武器/道具 → `items.json`；支援 → `supports.json`；
  - 章节数与敌人配置 → `chN_units.json`；商店 → `chN_shops.json`；胜利条件 → `chapter_objectives.json`。
- 流程：编辑 JSON → `validate`（校验）→ `generate`（生成 C89）→ `check`（漂移门禁）。命令见 `5.改版工程手册.md` §4。
- 改数原则：**公式不动表，表不动公式**。平衡调整只改表，公式改动必须更新本文件并标注版本。
- 所有数值沿 GBA 火纹经典曲线设计（调研报告第 4.2 节的规格基准），可直接进入 playtest 调参阶段。
- **注意**：第 1 节战斗公式对应原版 FE8 的战斗结算代码。凡标注"沿用原版"的条目，改版时保持不动即可；标注"本项目改写"的条目需改代码（见设计文档 §11 改造清单）。

## 1. 核心战斗公式（定稿）

> 实现位置：原版 FE8 战斗结算代码（`src/`，见设计文档 §12）；凡"本项目改写"项通过 `include/expansion_mechanics.h` 的机制钩子介入。

### 1.1 面板命中与回避

- **命中 = 武器命中 + 技×2 + 幸运÷2 + 克制修正 + 支援修正 − 敌方回避**
- **回避 = 攻速×2 + 幸运 + 地形回避 + 支援回避**
- **实际命中率 = clamp(0, 100, 命中 − 回避)**
- **判定：双随机数（2RN）**——取两个 0~99 随机数的平均值与命中率比较（火纹传统：让 90% 更稳、30% 更飘，减少"高命中连空"的挫败感）

### 1.2 伤害与追击

- **物理伤害 = 力 + 武器威力×特效倍率 − 敌方防御 − 地形防御**
- **法术伤害 = 魔 + 法器威力×特效倍率 − 敌方魔防 − 地形防御**
- **攻速 = 速度 − max(武器重量 − 体格, 0)**；**攻速差 ≥ 4 触发追击**（二次攻击）
- 特效倍率：克制系武器 ×1.5（斩马刀对骑、猎弓对飞等，见 2.6）；照夜/明烛对凶相尸傀 ×1.5
- 伤害下限为 0（不破防不掉血，但保留命中/暴击演出）

### 1.3 克制修正（数值锚点）

- **兵刃三环**（枪克刀、刀克锤、锤克枪）：克制方 **+15 命中、+1 威力**；被克方 **−15 命中、−1 威力**
- **三才法环**（天克地、地克人、人克天）：同值（+15/+1 与 −15/−1）
- **剑不入三环 / ★神器不入环**：双方均无修正（见 2.1、3.1）

### 1.4 必杀

- **必杀率 = 技÷2 + 武器必杀 + 职业必杀加成 + 支援必杀 − 敌方幸运（必杀回避）− 支援必杀回避**
- **必杀伤害 = 伤害 × 3**（先算普通伤害再乘，火纹传统）
- BOSS 级敌人自带必杀回避 +10（防止被秒杀演出打断节奏）

### 1.5 经验值

- **战斗基础经验 = max(1, 10 + (敌方等级 − 己方等级) × 2)**
- **击杀奖励 +10；击杀 BOSS +30**
- **治疗/辅助：固定 10 + max(0, 目标等级 − 施术者等级)**
- **等级差惩罚**：己方等级高于敌方 5 级经验减半；高 10 级固定为 1（防刷级保平衡，配合永久死亡的风险设计）
- **100 经验 = 升 1 级**；升级加点按成长模式（随机 / 固定，设计文档第 2 节）

## 3. 神器（★ 档）

**神器 = 圣皇燧铸鼎时的余料所铸兵器**，共九件散落九州（呼应"九"的主题数）。每件有专属外观、独特效果、专属数值——是玩家的长期追求目标，也是战斗画面的高光时刻。**神器即武器五档体系中的 ★ 档**（完整体系见第 2 节）。

### 3.1 通用规则（五条）

1. **不入三环**：神器对兵刃三环既不克制也不被克制——与"剑不入环"同源：圣皇所铸之物，不受人间兵刃谱系约束。（数值上给"高综合面板"作为补偿）
2. **黯淡机制**：耐久归零**不消失**，进入"黯淡"状态（威力/命中减半），用剧情道具**龙髓**修复；第 14 章后邓阿七的铁匠铺可修理——耐久系统与阵容绑定，制造"关键时刻用不用神器"的取舍。
3. **人器绑定**：专属神器绑定持有者，不可交易、不会掉落、敌人不可拾取。
4. **美术减负**：神器特效 = 专属配色 + 粒子层（白焰剑气、青辉音波、雷光链），**不新增战斗动画骨架**——对齐设计文档第 4 节"换皮派生"方案，预估每件额外 4~8 小时。
5. **获取剧情化**：全部剧情获得 / 外传 / 隐藏宝箱，不进商店——每件神器都是一个故事节点。

- **照夜与流照是"成对"的**：守鼎人双世家的信物之器，第 4 章双圭共鸣、第 20 章"山河为聘"削簪——主角感情线的道具链全程由这两件神器承担。

- 面板九维：**HP / 力 / 魔 / 技 / 速 / 运 / 防 / 魔防 / 体格**，外加**移动力**（由职业决定）。

- 体格影响攻速惩罚（见 1.2）与"救出/背负"判定（v1 可不做救出，留接口）。

### 5.2 转职规则（对接设计文档"每链 1~3 阶"）

- **转职条件**：低→中 Lv10 以上；中→高 Lv15 以上（数据化配置，各链可微调）。
- **转职结算（火纹传统"补差法"）**：属性按 **（目标职业基值 − 原职业基值）** 逐项补差（负差不扣）；等级重置为 Lv1；已积累属性保留；武器熟练度保留；新解锁武器系熟练从 0 起。
- **造型**：转职换调色板 + 装饰帧（设计文档第 4 节减负方案），不新增骨架。

## 8. 支援战斗加成

- **生效条件**：支援双方在战场上**相邻 1 格**；多人可叠加（最多取 2 人生效，防堆叠）。
- **加成表**：

| 等级 | 命中 | 回避 | 必杀 | 必杀回避 |
|---|---|---|---|---|
| C 相识 | +5 | +5 | 0 | 0 |
| B 相知 | +10 | +10 | +5 | 0 |
| A 生死之交 | +15 | +15 | +10 | +10 |

- **支援点积累**：相邻结束回合 +2；共同攻击同一敌人 +1；治疗对方 +1。阈值：**C=30 / B=70 / A=120**。
- 虞聪×沈婉莹主线感情线支援等级由剧情锚点解锁（《剧情与世界观设定》5.1），战斗加成照常生效——叙事与数值双奖励。

### 11.2 双难度（设计文档 P4）

- **普通**：按本文件数值。
- **困难**：敌数量 +20%、敌全属性 +10%、增援提前 1~2 回合、商店价格 +25%。
- **永久死亡**：默认经典（战死离队 + 专属退场台词）；可切"撤退模式"（战败退回整备，本章不可再用）。

### 11.3 软上限保护

- 经验等级差惩罚（1.5）+ 章节商店档位锁（7.2）双保险，防止"刷一章碾压三章"。
- 外传为可选挑战关：经验产出高但敌强，是给"想刷的玩家"的泄压阀。
