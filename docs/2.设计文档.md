## 0. 目标与范围

- **目标**：一部约 20 章完整故事线、单线推进的原创世界观 SRPG，玩法与观感致敬 GBA 火焰纹章（像素风、切屏战斗动画），剧情由用户自行设计。
- **游戏名**：**《山河烬》**（已拍板；同名检索无商业游戏冲突，正式发布前做商标检索）。**英文名（暂定）**：*Realm in Ashes*（随工作目录命名启用，发布前随商标检索一并确认）。
- **成功标准**：完整可通关 20 章；玩家（自己 + 同好）评价"有 GBA 火纹味"。
- **发布**：免费分享给同好；**Android 优先（手机玩最方便），Windows 版同步（开发与验证），Web 可选**。
- **v1 明确不做**：联网对战、商业化、多语言（先中文）、多周目差分、iOS。
- **体量红线（v0.5 新增，待拍板）**：20 章为目标体量；**12~15 章为可接受缩水线**（砍掉部分中幕章节、外传优先保留），在 P3 demo 决策门时按实际产出速度再评估——solo 开发防止"全或无"烂尾。

## 2. 核心玩法（demo 阶段）

- **网格**：地图格 16×16 像素，可视 15×10 格；地形移动力消耗。
- **回合**：玩家回合 / 敌方回合。
- **战斗公式**：以 **《游戏数值设定.md》第 1 节为唯一来源**（命中/回避/伤害/攻速追击/必杀/克制修正/经验，含 2RN 判定）。本文档不再内嵌公式——v0.4 版内嵌的"命中/伤害/暴击率"四条已废弃，避免双处维护漂移。
- **克制关系（v0.4 确立，v0.5 修正表述）**：克制方 **+15 命中、+1 威力**（点，不是百分比），被克方反之——
  - **兵刃三环**：枪 → 刀 → 锤 → 枪；**剑不入环**（中立生态位，主角/剑客系）；
  - **三才法环**：天克地、地克人、人克天；
  - 弓、弩在环外；克制标签只对攻击类法术生效，治疗/净化类不参与。
- **敌方 AI**（v0.5 细化，数值文档 10.3 为参数来源）：
  - v1：就近优先攻击（权重：**可击杀 > 伤害期望 > 命中率**）+ 驻守型（BOSS/卫兵不移动）+ 增援型（按波次入场后转就近）；
  - v1.1（P2）：盗贼优先开宝箱后向撤离点逃跑（火纹经典，配合宝箱设计）；
  - v2（P4）：治疗/辅助行为、护送目标保护权重。
- **战场信息 UX（v0.5 新增，火纹手感三大件）**：
  - **战斗预测面板**：选定攻击目标后、确认前，显示双方伤害/命中/必杀/追击/克制/地形修正后的完整预测；
  - **危险范围**：快捷键/按钮切换全体敌人攻击范围叠加层；长按单个敌人看其个人范围；
  - **单位详情**：长按单位查看五维/装备/熟练度/支援关系；长按地形查看地形效果。
- **悔棋（v0.5 新增，待拍板）**：每章 3 次"回溯到本回合开始"（消耗品式，章末不结转）；实现=每回合开始快照 GameState，回溯=恢复快照。
- **经验与成长**：个人成长率 + 职业成长加成，100 经验升 1 级（经验公式见数值文档 1.5）；**两种模式可选（开档/设置切换）**：随机成长（经典）/ 固定成长（百分点累计）。
- **转职**：每条职业链可转职 1~3 次，满足等级要求即可转（低→中 Lv10+、中→高 Lv15+，数值文档 5.2"补差法"结算）；转职树完全数据化配置。共 **15 条职业链**，见世界观圣经 3.3。
- **神器系统**：9 件神器（圣皇铸鼎余料所铸）。规则与数值见数值文档第 3 节；特效=专属配色+粒子层，不新增动画骨架。
- **说得系统（demo 必做）**：特定角色对特定敌人"说得"，成功则加入/提供情报，失败消耗一次行动；第 3 章郡丞卫队长为首个用例。**说得是战场指令，不是胜利条件**（v0.4 误列，v0.5 修正）。
- **支援与感情线**：义理值四档陌路→相识→相知→生死之交；战斗加成（C/B/A=命中回避 +5/+10/+15，见数值文档第 8 节）；彩蛋结义（石阿满/虞聪/燕不归）。感情线双轨制（世界观圣经 5.1）；**demo 阶段 C/B 对话用章节事件承载，正式支援系统（义理值/对话库 UI）在 P4 接入**。
- **物品栏与仓库（v0.5 新增）**：每人 5 格物品栏；章节间仓库 100 格；战斗中物品栏满时新物品可现场转存仓库；交易在相邻友军间进行。
- **出击与整备（v0.5 新增）**：每章战前进整备界面——**选人（上限 6~12，关卡表配置，主角强制出击）**、换装、查看成长/支援、商店、**战前情报**（预览本章敌人构成与胜利条件——配合特殊兵谱"读关选装"策略，数值文档 2.6）。
- **商店/装备/耐久**：武器与道具有耐久消耗；普通武器不修（用完即弃）；神器走"黯淡+龙髓/铁匠铺"独立规则。
- **存档**：3 个存档槽 + 战斗中断存档 + **每回合自动中断存档**（v0.5 新增）。

## 3. 章节结构

- **五幕 20 章**（结构详见世界观圣经第 4 节）：一·故乡失火（序~4）→ 二·帝都迷局（5~7）→ 三·北地真相（8~12）→ 四·会盟天下（13~16）→ 五·归墟决战（17~20）+ 外传 2 个（白鹤观旧事 / 幽都判官）。
- 每章流程：开场剧情（史书体旁白，世界观圣经 4.3 定调）→ **战前情报 + 整备** → 战斗 → 战后剧情。
- 胜利条件类型（v0.5 修正）：全灭 / 护送 / 防守 N 回合 / 占旗压制 / 限时 / 攻城 / **BOSS 击退**（凶相类，HP 压至阈值触发剧情撤退）。
- **事件触发器类型（v0.5 新增，EventRunner 实现依据）**：回合数到达 / 区域进入 / 单位死亡 / 单位 HP 阈值 / 访问村庄房屋 / 说得 / 战斗对话（特定单位邻接）/ 章节开始与结束——剧情文档 4.5 的所有中场事件均可由这 8 类组合实现。
- **Demo = 序章~第 4 章（5 关）**，完整跑通全部系统后作为决策门验收；关卡配置见 `关卡表_Demo五章.md`。
- **教程策略（v0.5 新增）**：序章强制教学（移动/攻击/克制/护送）；此后新机制首次出现弹一次提示卡；设置中可重看全部教学（"温故"入口）。

## 4. 战斗画面（切屏动画）规格与减负方案

- 战斗场景 240×160：双方单位、背景按地形（平原/室内/山地等）。
- 动画集：每职业 4 段（待机/攻击/闪避/受击）+ 暴击变体；敌我仅换调色板。
- **减负策略（关键）**：15 职业链 → 合并为 **5~6 个基础骨架动画集**（步战、弓手、法师、骑乘、重甲、飞行、兽灵），换武器贴图 + 调色板派生全部职业；转职阶用调色板 + 少量装饰帧区分；**demo 先做 3 个骨架**：剑步（虞聪）、弓手（石阿满）、法师（温子墨/云虚，沈婉莹琴士共用）。
- **动画数据驱动（v0.5 新增）**：战斗动画 = 帧序列 + 时间轴配置（Resource），命中闪光/帧暂停/震屏/伤害数字/暴击触发均为时间轴事件点——调演出节奏不改代码。
- 素材：itch.io / OpenGameArt 上 CC0/CC-BY 像素包优先；主角关键动作自画；**不使用任天堂原版帧**。
- 演出脚本：进场 → 攻击帧 → 命中闪光 + 帧暂停(hitstop) + 震屏 → 伤害数字 → HP 条 → 退场。
- 工作量提示：全项目美术最大头，骨架复用方案约 150~250 小时。

## 5. 美术与音频规格

- 世界内部分辨率 240×160；**缩放 = 按设备高度取最大整数倍 + 黑边居中**（v0.5 修订）；禁用平滑过滤。
- 头像 96×80、限 16 色，含口型/眨眼帧；地图小人 16×16。
- **中文字体方案（v0.5 拍板建议）**：Fusion Pixel Font（缝合像素字体，SIL OFL 开源，覆盖简中，12px 渲染清晰）主用；备选 Zpix（最像素，OFL）。**布局铁律：正文文本（对话/菜单/数值）一律走屏幕空间 UI 层（UILayer/DialogLayer），不渲染进 240×160 世界层**——240 宽的世界层放中文只有 20 字/行，必死；世界层只保留伤害数字与极简图标。
- **音频规格（v0.5 新增）**：demo 阶段 **8 首 BGM 按情绪复用**（标题/地图-日常/地图-紧张/战斗-我方/战斗-敌方/剧情-温情/剧情-悲壮/终章）+ 战斗 jingle×2（暴击/Boss）；格式 OGG 带循环点；SFX 用 GDC Sonniss 免费包（剑击/弓弦/脚步/UI 音约 20 个）。
- 素材来源：PixelSRPG-Forge（中文，兼容 Godot）、Kenney（CC0）、OpenGameArt、itch.io 像素包；音乐 Kenney / incompetech（CC-BY）。
- 授权原则：只使用 CC0 / CC-BY / 明确免费商用许可的素材，或自画。

### 5.1 触摸 UI 适配

- 游戏世界保持 240×160 整数缩放；**UI 层用独立屏幕空间 CanvasLayer**（不跟随 viewport），按钮按设备物理分辨率布局，触摸目标 ≥ 48px。
- 横屏锁定（landscape）；操作方案：点选单位 → 再点格子移动/攻击 → 弹出行动菜单；拖动空白处卷动地图；长按单位看属性；屏幕角落放"菜单/结束回合/取消/危险范围"按钮（位置避开误触区）。
- 输入抽象层 `InputRouter`：统一接收"选择/确认/取消/拖拽"语义，键鼠与触摸两套映射，PC 与手机共用一套游戏逻辑。PC 补充：鼠标悬停即显示危险范围预览（键鼠优势操作）。

## 6. 技术架构（Godot 4）

- Godot 4.4+，GDScript，不依赖第三方收费插件；详细技术方案见 `技术设计文档.md`（TDD）。
- **渲染器**：Compatibility（OpenGL ES 3.0），覆盖几乎全部安卓设备。
- **安卓导出环境**：OpenJDK 17 + Android SDK；开发期在 Windows 做，编辑器"触摸模拟"验证，每阶段至少一次真机 adb 测试。
- **数据驱动**：职业/物品/角色/章节/对话全部用 Resource（.tres）或 CSV 表；**公式参数也进配置表**（克制修正、经验公式系数、支援加成等，"公式不动表，表不动公式"——数值文档第 0 节原则）。
- Autoload：`GameState` / `BattleCalc`（含 `predict()` 预测接口，供战斗预测面板调用）/ `Pathfinder` / `EventRunner` / `UnitFactory` / `InputRouter` / `AudioBus`。
- 场景树：Title → MapScene（WorldLayer/UILayer/DialogLayer）→ BattleScene → MenuScenes（整备/商店/存档/设置）。
- 存档：JSON + 简单校验，3 槽 + 中断 + **每回合自动中断档**（v0.5）。
- 参考仓库（只读参考，不直接内嵌）：TBS_GoDot、godot_grid2D、FireEmblem4_5_Remake。

## 7. 分期路线图（两段式）

- **P0 第 1~2 周**：装 Godot 4 + GDScript 入门 + 跑通 TBS_GoDot；装好安卓导出环境并导出空 APK 到手机验证链路；**验证 Fusion Pixel 字体在 UI 层的渲染**。
- **P1 至第 2 月**：战斗内核——tilemap 移动、A* 寻路、回合、战斗公式（按数值文档第 1 节）、经验成长、永久死亡；**战斗预测面板 + 危险范围（核心手感，与内核同期做，不是后期 polish）**；同步做 InputRouter 与触摸操作；自动中断存档。
- **P2 至第 3 月**：内容管线——章节事件（8 类触发器）、对话、商店、存档、转职（数据层 1~3 阶，demo 内容 1~2 阶）、说得系统（第 3 章用例）、**战斗画面 v1（3 个骨架动画）**；按 `关卡表_Demo五章.md` 做序章~第 4 章；真机测试开始（每月至少一次）。
- **P3 第 4 月**：demo 验收——序章~第 4 章完整可玩（手机 + 电脑都试玩）→ **决策门：继续 Godot 扩 20 章 / 带素材转 SRPG Studio**；同时评估体量红线（20 章 vs 12~15 章）。
- **P4 第 5 月起**：全量——支援系统（义理值/对话库 UI）、外传、双难度、剩余职业动画、音乐、平衡测试。
- **P5 发布**：Android APK（itch.io/直接分享+侧载说明）+ Windows exe；Web 可选；Google Play 为可选项（$25）。
