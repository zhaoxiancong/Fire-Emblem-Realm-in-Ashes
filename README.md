# 山河烬 · Realm in Ashes

> 一款中国风原创战棋 SRPG 改版——以 GBA《火焰纹章：圣魔之光石》为骨架，讲一个「九鼎镇四凶」的乱世故事。

| 项 | 内容 |
| --- | --- |
| 中文名 | 山河烬 |
| 英文名 | Realm in Ashes |
| 类型 | GBA 火焰纹章风格战棋 SRPG（romhack） |
| 技术路线 | **FE8 反汇编扩展框架**（`fireemblem8-expansion`），`arm-none-eabi` GCC 从源码构建 ROM |
| 基底作品 | 《火焰纹章：圣魔之光石》美版（FE8U） |
| 画风 | **100% 还原原版**——原生复用原版 UI / 头像 / 地图 / 战斗动画资产 |
| 硬件规格 | GBA：240×160、15 色 + 1 透明、16×16 地图格 |
| 开发环境 | WSL2 (Ubuntu)，约 2.5 GB 磁盘 |
| 发布形式 | **补丁（.bps / .ups）**，免费分享，不卖钱 |
| 目标体量 | 20 章（缩水线 12~15 章），Demo 5 章 |

## 仓库结构

采用**方案 B（内容外置）**：基底框架作为**只读依赖**（由 `framework.lock` 钉死 commit），原创内容全部住在本仓库。

```
Fire-Emblem-Realm-in-Ashes/
├── docs/            # 11 份设计文档 + images/（矢量配图）
├── tools/           # 17 个脚本：环境搭建(1~7) / 一键诊断(shanhe.sh) / 体检(git-health.sh)
│   ├── shanhe-build.sh        # ★ 日常唯一入口：内容同步 + 构建 + 导出
│   └── wsl/                   #    必须在 WSL 内运行的工具
├── content/         # ★ 原创内容：data/ texts/ src/ assets/
├── framework.lock   # ★ 框架依赖声明（commit + 子模块 + 基线 SHA1）
├── GIT_WORKFLOW.md  # 提交规范
└── .gitattributes   # 统一 LF 行尾
```

**重建（换机 / 新克隆）三条命令**：见 [`docs/5`](docs/5.改版工程手册.md) §3.6 或 [`docs/6`](docs/6.方案B内容外置规划.md) §1.1。
