# 山河烬 · Realm in Ashes

> 一款中国风原创战棋 SRPG——以《火焰纹章》为骨架，讲一个「九鼎镇四凶」的乱世故事。

| 项 | 内容 |
| --- | --- |
| 中文名 | 山河烬 |
| 英文名 | Realm in Ashes |
| 类型 | 回合制战棋 SRPG（SRPG / Tactics） |
| 引擎 | Godot 4.4+（GDScript，Compatibility / GLES3 渲染器） |
| 首发平台 | Android（横屏），后扩 PC |
| 美术规格 | 240×160 逻辑分辨率 + 像素风，UI 层走高清中文 |
| 目标体量 | 20 章（缩水线 12~15 章），Demo 5 章 |

## 文档体系（SSOT 三分）

所有设计只在这三个文件里有唯一权威版本，其他地方一律引用、不得复制粘贴数值。

| 文件 | 职责 | 版本 |
| --- | --- | --- |
| [`docs/0.调研报告.md`](docs/0.调研报告.md) | 技术选型与竞品调研（路线 A/B 决策依据） | v1.0 |
| [`docs/1.剧情与世界观设定.md`](docs/1.剧情与世界观设定.md) | 世界观、人物、章节剧情、感情线 | v1.3 |
| [`docs/2.设计文档.md`](docs/2.设计文档.md) | 系统设计与玩法定性描述（不含数值） | v0.5 |
| [`docs/3.游戏数值设定.md`](docs/3.游戏数值设定.md) | **所有数值的唯一来源** | v0.1 |

> 铁律：设计文档只写「意图与规则」，**任何数字**都写进 `3.游戏数值设定.md`。
